# Библиотека по модулям

В [main.py](main.py) уже работает консольная библиотека: 22 функции показывают книги, ищут их по названию и автору, оформляют выдачу и возврат, показывают читателей и статистику. Пока весь код находится в одном файле, и ориентироваться в нём неудобно.

Распределите готовые функции по модулям и пакетам. Поведение библиотеки должно сохраниться. Новые возможности добавлять не нужно.

## Что должно получиться

- Точка входа остаётся в `main.py`. В нём находятся импорты, функция `main()` с управлением программой и защищённый запуск этой функции. Остальные 21 функцию перенесите в другие файлы.
- Создайте не менее двух собственных пакетов с `__init__.py` и не менее четырёх модулей с рабочими функциями суммарно внутри этих пакетов. `main.py` и `__init__.py` в эти четыре модуля не входят. Каждый пакет должен содержать функции, которые используются библиотекой.
- Сами выберите названия пакетов и модулей и распределение функций. Объединяйте функции по смыслу: у каждого модуля должна быть понятная общая задача. Пустые файлы и копии функций не считаются разбиением.
- Сохраните имена функций, их параметры, начальные книги, результаты вычислений и изменения данных. Каждая исходная функция должна иметь одно определение. Можно менять обращения к функциям и добавлять импорты под выбранную структуру. Форматы строк, возвращаемых `format_book()` и `format_loan()`, также сохраняются.
- Данные текущего запуска создаются в `main()` и передаются функциям. Выдача должна сразу отражаться в каталоге, списке выдач и статистике; возврат — тоже. При новом запуске снова доступны все книги, выдач нет.
- Импорт любого вашего модуля или пакета, включая `main`, не открывает меню, не запрашивает ввод и ничего не печатает. Модули должны импортироваться независимо от порядка, без циклических зависимостей. Библиотека работает на обычном Python без сторонних зависимостей.

Имена и параметры всех функций уже указаны в исходном коде. Возвращать перенесённые функции в пространство имён `main` специально для проверки не нужно: они могут находиться в любых ваших модулях.

## Поведение, которое нужно сохранить

| Пункт | Действие |
| --- | --- |
| `1` | Показать все книги, включая те, у которых нет свободных экземпляров. |
| `2` | Запросить часть названия или имени автора; показать совпадения без учёта регистра. |
| `3` | Запросить ID книги, затем имя читателя; выдать один свободный экземпляр. |
| `4` | Запросить ID книги, затем имя читателя; вернуть выданный ему экземпляр. |
| `5` | Запросить имя читателя; показать только его текущие выдачи. |
| `6` | Показать все текущие выдачи. |
| `7` | Показать число названий, всего экземпляров, выданных и свободных экземпляров, читателей с книгами. |
| `0` | Завершить программу. |

После действия меню появляется снова. Неизвестный пункт вызывает сообщение и повтор меню. Пробелы по краям ввода убираются. Пустое поле ID, имени или поискового запроса запрашивается повторно; пустой выбор меню считается неизвестным пунктом. ID и имена читателей различают регистр: `Alex` и `alex` — разные читатели.

Одному читателю нельзя выдать второй экземпляр той же книги. Неизвестная книга, отсутствие свободных экземпляров и повторная выдача не меняют данные. Возврат несуществующей выдачи также ничего не меняет. При выдаче и возврате программа всегда сначала спрашивает оба поля, затем сообщает результат. Сообщения об успехе, ошибке и отсутствии результатов должны оставаться понятными.

Перед каждым вводом нужна английская подсказка, включая повторный ввод и выбор меню. Выведенные данные сопровождаются английскими подписями или пояснениями. Формулировки в готовой программе и примере — возможный вариант; другой текст подсказок и подписей допустим. Номера пунктов, порядок запросов и данные сохраняются.
